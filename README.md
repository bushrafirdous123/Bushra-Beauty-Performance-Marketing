# BUSHRA BEAUTY
### Performance Marketing & Campaign Analytics Portfolio

A simulated digital marketing case study for a D2C skincare brand, focusing on Meta Ads and Google Search Ads campaign analysis, performance measurement and optimization.

## Project Overview

This portfolio explores two paid advertising channels:

**1. Meta Ads – Lead Generation**
- 30-day simulated campaign dataset
- Audience analysis: Broad, Skincare Interests and Lookalike
- Creative performance comparison
- Audience and creative combination analysis
- KPI tracking and optimization recommendations

**2. Google Ads – Search Campaign**
- 30-day simulated Google Search Ads dataset
- Campaign and ad group analysis
- Keyword and match-type performance
- Device-level performance analysis
- Conversion tracking and ROAS analysis
- Keyword optimization recommendations

This is an independent simulated portfolio project created for learning and demonstration purposes. All campaign data, spend, clicks, leads, conversions and performance results are synthetic and do not represent actual advertising account performance or client work.
